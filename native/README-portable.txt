BARO COMPANION — справочник Barotrauma для Linux и macOS
========================================================

Нужна Java 21 или новее.
  Linux:  sudo apt install openjdk-21-jre   (или пакет вашего дистрибутива)
  macOS:  brew install openjdk@21            (или установщик с adoptium.net)

Запуск:
  Linux — в терминале:  ./run-linux.sh
          (или: java -jar BaroCompanion.jar; если архив распакован без прав на запуск —
          один раз: chmod +x run-linux.sh run-macos.command)
  macOS — двойной щелчок по run-macos.command в Finder.
          Если macOS не разрешает запуск: Системные настройки → «Конфиденциальность и
          безопасность» → «Всё равно открыть», либо один раз: xattr -dr com.apple.quarantine .

Настройки и журнал хранятся:
  Linux — ~/.config/BaroCompanion
  macOS — ~/Library/Application Support/BaroCompanion

Что работает так же, как в Windows: все вкладки, чтение файлов установленной игры и модов,
сейвы, иконки, оба языка. Данные игры ищутся в стандартных путях Steam; если игра не найдена,
используется встроенная копия. Папку игры и сейвов можно задать в настройках.

Окно поверх игры (Shift+T): глобальное сочетание работает и на Linux (X11), и на macOS.
  • Linux: под сессией Wayland клавиши, уходящие в нативные окна, могут не перехватываться —
    тогда окно открывается из самой программы.
  • macOS: поверх игры в полноэкранном режиме окно может не отображаться (ограничение системы) —
    используйте игру в оконном режиме.
